DOING-list (진행도 투두리스트)계획 단계를 단축하고 실행 지연을 막아주는 '진행도 게이지 바' 기반의 실용적인 PWA 웹앱 투두리스트현재 MVP 방향고객은 앱 설치 과정 없이 웹 브라우저를 통해 접속하며, PWA 서비스 워커를 통해 오프라인 상태에서도 앱처럼 서비스를 이용한다. 초기 진입 시 비회원(Guest) 상태로 기기 로컬 스토리지에 할 일을 저장하며, 로그인 시 기존 로컬 데이터를 Supabase DB로 병합(Append)하여 마이그레이션한다.메인 화면에서는 모든 하위 업무의 달성 비중을 동일하게 계산하여, 하위 투두리스트 완료 시 화면 깜빡임 없이 상위 투두리스트의 진행률(%) 게이지 바가 즉각적으로 업데이트된다. 복잡도와 피로도를 낮추기 위해 사용자가 가중치를 직접 설정하는 기능이나 무거운 AI 요약/추천 기능은 제외되었으며, 오직 직관적인 시각화와 템플릿 제공이라는 본질에 집중한다.Plaintext사용자 입력 (온/오프라인 환경)
  → 프론트엔드 상태(Zustand) 즉각 업데이트 및 화면(게이지 바) 렌더링
  → 비회원: 브라우저 localStorage에 CRUD 처리
  → 회원(온라인): Supabase DB로 동기화
